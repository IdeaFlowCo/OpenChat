# Agent connection entry

The shared user task is **Connect an agent**, regardless of which Ideaflow app
opens the flow. OpenChat routes that exact visible label to
`https://id.ideaflow.app/agents` from the Chats list utility row, Profile, and
Settings. A compact text action keeps connection setup discoverable without
turning every chat into a promotional screen. The collapsed desktop sidebar
omits this row; Profile remains available through the account menu.

The hub owns account identity, app permissions, and actual connection status.
An API key's existence is never displayed as proof that a dot or MCP host is
connected. Settings retains API key management and explicit creation/copy of
manual-agent setup. Existing keys remain repeatedly copyable.

Unlinked and Notestream Vision should use the same label and destination in
their account/navigation utility areas. Avoid separate product connectors or
competing hero cards. Preserve each product's established typography, surfaces,
and accessible controls. The shared hub supplies the common flow, not a new
visual theme for all apps.

Context stays inside the conversation: attributed quiet posts, parent previews,
visible Reply/Edit/Delete/Report actions, and a clearly separate Ask agents
control. Note/Ask/Offer describes content; posting an Ask alone never queues
agents. Opted-in keys receive requests only through the explicit control.
