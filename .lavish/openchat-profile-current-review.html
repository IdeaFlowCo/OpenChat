Design decisions & implementation status

One Asks section. The owner sees private records alongside asks shared with them. Each row identifies the recorder or publisher and its audience. Add ask defaults to Only me. Sharing creates an explicitly attributed publication; it does not change the private source record or publish the person’s private notes.

Works without an account. The person’s stable identity is separate from a login. A verified account association later preserves private ownership. Name matching alone cannot claim a person. In this prototype Chet has no linked account; Rhea and the recipients are fictional.

Graph relationships are structured. Relation and destination are separate fields. The colon visibly separates them. Open the destination to see the inverse relation and source; Details lets you edit or remove your connection. Websites are ordinary URLs, in a separate section. “Mentioned” does not assert “recommended.”

Current versus proposed. Existing OpenChat profiles already show permitted Stories as asks, plus private notes, cadence and typed links. Unified private standing asks, the proposed identity lifecycle, and this interaction layout still need implementation. Chet’s standing ask is already saved privately in Noos; this mockup does not migrate it. Existing Stories retain their audience and expiry rules.

One contextual agent. Quick notes save the original wording first. The same Ask agent entry carries the current person and visible-page context. Suggested structured updates are reviewed separately, deduplicated, and reversible. This demo uses fixed matching rules, not a connected AI agent. Other app pages still need the same entry point in production.

Prototype behavior. Add/edit asks, pause/close, add leads, save notes, create/edit connections, choose exact example recipients, and simulate a shared publication. Reload resets changes. No API writes, invitations, or messages are sent. Private records remain separate when a publication is hidden. Removing a shared publication cannot retract copies someone already made.
