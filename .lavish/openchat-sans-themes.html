Sources & what this preview represents

Design source: the requested Unlinked scheme, using OpenChat’s actual embedded tokens from apps/mobile/src/theme/colors.ts at 50e2c3d. Indigo light keeps the embedded background #f5f6fc, accent / outgoing bubble #4349c4, border #e6e8ef, and metadata #606576. Public Sans comes from Unlinked’s outer-page stylesheet; the embedded chat currently uses system sans. The warm option retains OpenChat’s Ink & Paper palette with sans-serif headings. Neutral ink, deep green, and the indigo dark counterpart are proposed palettes. The October 6 feedback selects Warm Paper + System Sans as the preferred direction. Its revised dark proposal uses warm charcoal and a muted outgoing bubble instead of the earlier pale bubble; it is no longer a copy of production dark tokens.

This is a working HTML design study based on the canonical React Native client’s sidebar, conversation header and composer. Sample people and messages are fictional. It is not a screenshot or a connected inbox. Fonts are bundled locally under the SIL Open Font License. A production pass would apply the chosen type throughout the shared native/web client and verify native font rendering. No production theme has been changed.
