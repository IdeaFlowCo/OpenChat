1 Emoji as UI icons

📎 💙 🎤 💬 💭 📋 🤖 🗑 render from each OS's emoji font: different shapes per platform, full-color glyphs that ignore your theme, mixed metaphors, no shared stroke weight. This is the single biggest "unfinished" signal. Fixed in PR #22 for composer, tab bar and the new sheet actions with a single SVG line-icon set (below); the rest of the app (action sheet legacy rows, FAB, "ⓘ", arrows) should follow.

2 Stock-Tailwind palette = no identity

Primary blue-500 + gray-100/200/400/500/900 is the default of every scaffolded app. The same blue is used for your bubbles, buttons, links, tab highlight and pins — so nothing reads as special, and the app has no recognizable color voice.

3 Flat hierarchy

Every surface is a 12-radius card with the same hairline border; type is system-font at 3 nearly-identical sizes. Nothing is loud, nothing is quiet — headers, cards, bubbles and chips all carry equal visual weight.

4 Header clutter & mixed glyph systems

"ⓘ", text arrows (↓ ↩ ↪ ✎) and emoji live side-by-side in the chat header and action sheet. One icon system should own all of it.

Shipped already in PR #22 — the new line-icon set (react-native-svg, themable, identical on iOS/Android/web)

These work under any of the directions below — the palette and shapes change, the icon language stays.

2 · Three from-scratch directions

Each mockup shows the same chat plus the new chat-scoped Thoughts card, so differences are directly comparable. All three keep the shipped icon set and the pin/save-to-stream flow.

A · Ink & Paper

Warm paper ground, near-monochrome ink, one burnt-sienna accent, serif display type. Thoughts read as index cards. Calm, literary — fits "a thinking layer over your conversations."

Cost: serif + warm palette needs careful dark mode; most rework of type styles.

B · Deep Graph

Dark-first, indigo→cyan gradient as the one signature move (your bubbles, mic, pins), glassy slate surfaces. Leans into the Noos / knowledge-graph identity — "Global Brain" made visible.

Cost: light mode becomes the secondary theme; gradients need restraint to avoid 2021-crypto vibes.

C · Signal

High-contrast neutral: black on white, heavy weights, tight letter-spacing, one vivid coral accent reserved for actions (mic, pins, unread). Feels like iMessage × Linear. Cheapest to execute — mostly token swaps on today's layout.

Cost: least distinctive of the three; identity carried almost entirely by the accent + typography discipline.
